# 三和弦：横按和弦里"藏"着的免横按指型

之前聊过：普通和弦并不是非要 6 弦全响不可，横按也只是"保留六弦满弦形状"时的权宜之计。这份文档把这个想法落到实处——**从已经验证过的横按和弦指型里，直接抠出中间 3 根弦，就是一个不用横按、不用空弦、能自由移调的三和弦**。

数据来自 [吉他和弦分类一览.md](./吉他和弦分类一览.md) 第四节的 E 型/A 型横按和弦（R=5 的示例），这里只是换个角度重新展示。

## 一、E 型横按 → 取 1、2、3 弦（e、B、G）

E 型横按和弦本身是 `R R+2 R+2 R+1 R R`（6 弦→1 弦）。只看最上面 3 根弦（1e、2B、3G），三音齐全，根本不需要横按：

### 大三和弦（示例 R=5 → A 大三和弦）

| 弦\品 | 5(R) | 6(R+1) | 7(R+2) |
|---|---|---|---|
| 1（e） | A4 |  |  |
| 2（B） | E4 |  |  |
| 3（G） |  | C#4 |  |

三个音 A4、E4、C#4 = A、E、C# = 根音、五音、三音，一个完整的 A 大三和弦，三根手指各按一根弦，没有横按。

### 小三和弦（示例 R=5 → A 小三和弦）

| 弦\品 | 5(R) | 6(R+1) | 7(R+2) |
|---|---|---|---|
| 1（e） | A4 |  |  |
| 2（B） | E4 |  |  |
| 3（G） | C4 |  |  |

跟大三和弦相比，只有 3 弦从 R+1 变成 R，也就是**三音降半音**——大小三和弦在这个三弦指型上只差一根手指挪一品，非常直观地体现了"大小三度只差半音"这个乐理概念。

## 二、A 型横按 → 取 1、2、3 弦（e、B、G）

A 型横按和弦是 `x R R+2 R+2 R+2 R`（6 弦闷音）。同样取最上面 3 根弦：

### 大三和弦（示例 R=5 → D 大三和弦）

| 弦\品 | 5(R) | 6 | 7(R+2) |
|---|---|---|---|
| 1（e） | A4 |  |  |
| 2（B） |  |  | F#4 |
| 3（G） |  |  | D4 |

A4、F#4、D4 = D、F#、A，一个完整的 D 大三和弦。

### 小三和弦（示例 R=5 → D 小三和弦）

| 弦\品 | 5(R) | 6(R+1) | 7(R+2) |
|---|---|---|---|
| 1（e） | A4 |  |  |
| 2（B） |  | F4 |  |
| 3（G） |  |  | D4 |

同样的规律：三音那根弦（2 弦）从 R+2 降到 R+1，大三变小三。

## 三、这套指型的实际用处

- **换弦即兴/伴奏时更干净**：乐队里贝斯已经把根音撑住了，吉他弹这种 3 音三和弦，声音更透、更不容易和贝斯"打架"，比满弦大和弦更适合放克/流行的节奏吉他。
- **移调只需要移动这一个小形状**：跟横按一样，整个指型平移，根音跟着变，参考 [音名全表.md](../音名全表.md) 查某一品是什么音就知道换到哪个调了。
- **同一个道理可以推广到 2、3、4 弦或 3、4、5 弦**：把 A 型横按最下面 3 根弦（4D、3G、2B）单独拿出来，也能抠出一个不同"排列方式"的三和弦（三音在最下面），感兴趣可以照着 [吉他和弦分类一览.md](./吉他和弦分类一览.md) 里的横按公式自己再推一组。
