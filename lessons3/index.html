学完主线，要能做什么？
跟大调和小调 ii–V–I 弹短句；用目标音、休止和一个动机组织 solo；在简化 jazz blues 里跟上和弦。音阶是选音材料，节奏、听觉与解决让它成为音乐。

和现有两套课程怎么接

Lessons：建立音名、三和弦、大调、五声音阶与布鲁斯基础。
Lessons 2：把基础转为指板导航、目标音、声部连接、练耳与 CAGED。
Lessons 3：新增七和弦、爵士节奏、ii–V–I、半音语言、小调与真实录音模仿，把这些变成 solo。

无需先背完五个指型，也不要求大横按。第 1 课会诊断认音与数拍；缺什么就回补什么。课程已写好不代表你已经掌握；目前没有演奏过关证据。

01 · 找到落点

先用和弦音说话

只用两个音起步 → 七和弦 → 导向音。

作品：跟 ii–V–I 弹两条导向线。
01 / CORE只用两个音，开始 solo跟 Dm7 伴奏弹 4 小节，不丢拍；同一短句重复一次，再改变节奏。02 / CORE七和弦：solo 的骨架说出并弹出 Dm7、G7、Cmaj7 的四个和弦音。03 / CORE三音、七音，连出 ii–V–I在 Dm7–G7–Cmaj7 中，听见并弹出 F4 → F4 → E4。
02 · 音阶有了语境

让同一组音换一种口气

Swing 与留白 → Dorian → Mixolydian / Ionian。

作品：一条能听见色彩和解决的四小节短句。
04 / CORESwing、弱拍与留白用同一组音弹出两句：一句正拍起，一句弱拍起。05 / COREDorian：听见小调里的大六度在 Dm7 上比较 B4 与 B♭4，做一条以 F4 或 C4 落地的 Dorian 短句。06 / CORE同一组音，换一个落点在 G7→Cmaj7 时，把 F4 引向 E4，把同一音阶弹出和弦方向。
03 · 连成一段 solo

重复、装饰，再解决

8 小节创作 → 半音趋近 → 属 bebop。

作品：带一个动机、一次装饰的 8 小节 solo。
07 / CORE第一段 8 小节爵士 solo把相同节奏动机用于两轮 ii–V–I，第二轮只改变结尾。08 / CORE半音靠近：把“外音”带回家用一个半音趋近或三音包围，在换和弦时落到 E4。09 / COREBebop 音阶：把音放回拍点从 G4 正拍下行八分音符，让 G7 和弦音落在四个拍点。
04 · 走进小调

让张力回到小调主和弦

半减七与 V7 → 和声小调 → 爵士旋律小调。

作品：能分清三种小调材料的落点练习。
10 / CORE小调 ii–V–i：先抓三个三音以 D4→G#3→C4 三个三音，跟住 A 小调的 ii–V–i。11 / CORE和声小调：把张力用在 V7在 E7(♭9) 上使用 A 和声小调，并用 F4→E4、G#3→A3 解决。12 / CORE旋律小调：给小调终点换颜色在小调主和弦上比较自然、和声、爵士旋律小调的六级与七级。
05 · 成为自己的句子

听真实演奏，录真实作品

Jazz blues → 模唱与变奏 → 16 小节项目。

作品：独立录两轮，隔日能再弹出来。
13 / CORE从布鲁斯走进 Jazz Blues在 12 小节 F jazz blues 中，区分蓝音张力与和弦落点。14 / CORE耳朵采一句，再长成自己的句子听写或模唱一小段节奏，再用自己的音高作两次变化。15 / CORE结课：弹一段有方向的 solo在大调 ii–V–I 上录两轮共 16 小节；有重复、留白、和弦落点和一次张力解决。
选修 · 在稳定之后

每次只添一种颜色

Lydian Dominant → Altered → 减音阶。

先修门槛：15 课作品稳拍、落点清楚。
16 / OPTIONALLydian Dominant 的 ♯11在静态 G7 上比较 C4 与 C#4，再把 #11 引向 D4。17 / OPTIONALAltered：外音要有出口在 G7alt→Cmaj7 中，让 A♭4→G4、E♭4→E4 各解决一次。18 / OPTIONAL减音阶：先分清半全与全半在 G7(♭9) 上用半全减音阶，最后解决到 Cmaj7。

一节课怎么练

  1. 2 分钟检索：不看图，唱或弹上一课的两个落点。
  2. 5 分钟新材料：读一个概念，先听示范、唱一句，再拿琴。
  3. 5–10 分钟应用：关掉示范跟伴奏弹，录两轮，只修一个问题。
  4. 隔 1、3、7 天：不看旧谱重弹，再交替练相近但不同的材料。

这些是每次练习时长，不是掌握期限。可以一天读几课；进入下一阶段以录音标准为准。手跟不上时减少音数，理论理解不必等手速一起长。
