和弦功能与终止式：为什么歌曲这样结尾

这一课不加新和弦、不加新手型——纯粹用你已经会弹的 C、Dm、Em、F、G、Am，搞懂"一句和弦为什么听起来像结束了"，还是"像没说完"。

上一课：常用和弦进行 ・ 参考卡：和弦功能与终止式

7 个和弦，三种角色

顺阶和弦不是 7 个互相独立的选项，它们按"角色"分成三组：

功能C 大调里对应感觉
主功能（Tonic，"家"）I（C）、vi（Am）稳定，可以停留
下属功能（Subdominant，"出门"）IV（F）、ii（Dm）离开主音，但不紧张
属功能（Dominant，"路上"）V（G）、vii°（Bdim）紧张，很想解决回 I

一句和弦进行的基本叙事，就是主 → 下属 → 属 → 主：从家出发，路上制造一点紧张，最后回家。 不是所有歌都严格按这个顺序走，但几乎每个和弦选择，背后都在往这三个角色里落。

四种"收尾"公式：终止式

一句和弦进行怎么结束，几乎都逃不出这 4 种公式：

终止式走向C 大调实例效果
完全终止V → IG → C最强的"回家"感，最常见的结尾
半终止任意 → V… → G停在悬念上，像没说完的话
变格终止IV → IF → C比完全终止柔和（"阿门终止"）
阻碍终止V → viG → Am本该回家却被"骗"到别处
动手听：弹一遍，对比感觉 每组只弹两个和弦，一个和弦一小节，弹完停住感受一下"结束了吗"：
  1. G → C（完全终止）——应该感觉"到家了，可以停"。
  2. C → G，弹完停在 G 上（半终止）——应该感觉"还没完，在等下一句"。
  3. F → C（变格终止）——也是回家，但比第 1 组更"软"，没那么斩钉截铁。
  4. C → F → G → Am，注意最后落在 Am 而不是 C（阻碍终止）——应该感觉"咦，怎么没回 C"，有点意外。
推荐阅读 Hooktheory 的 TheoryTab 数据库能查到真实歌曲在哪用了阻碍终止、哪首歌是完全终止收尾，把这几种终止式套进真实歌曲里再感受一遍，比单看和弦表更有感觉。
