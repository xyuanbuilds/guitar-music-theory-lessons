# 音阶 + 指型 对应指板图（C大调及相关）

规则：1 弦在上，6 弦在下。只标该音阶的音，空白为非音阶音。**加粗**为当前调式的根音。每个图下面注明三音位置，方便你盯色彩。

从根音开始和结束，三音加重，短乐句必须能回家。

> 这份文档专注"指板定位 + 根音/三音听辨"的手指训练。调式的音阶公式、特征音、和弦怎么配调式，见配套的 [调式理论基础.md](./调式理论基础.md) 和 [和弦音阶对应表.md](./和弦音阶对应表.md)。

## 图1：C Ionian（C大调）C 型（C-shape）指型（0–5品，你现在的 C3 区域）

这是最基础的 C-shape，C3 就在 5 弦 3 品。核心指型在 0–3 品，4–5 品是延伸到下一个 A 型指型的过渡音。

| 弦/品 | 0 | 1 | 2 | 3 | 4 | 5 |
|-------|---|---|---|---|---|---|
| 1弦（e） | E4 | F4 |  | G4 |  | A4 |
| 2弦（B） | B3 | **C4** |  | D4 |  | E4 |
| 3弦（G） | G3 |  | A3 |  | B3 | **C4** |
| 4弦（D） | D3 |  | E3 | F3 |  | G3 |
| 5弦（A） | A2 |  | B2 | **C3** |  | D3 |
| 6弦（E） | E2 | F2 |  | G2 |  | A2 |

**根音 C**：5弦3品 C3、2弦1品 C4、3弦5品 C4。
**三音 E（大三度，色彩）**：4弦2品 E3、2弦5品 E4、1弦0品 E4、6弦0品 E2。

先把这个图形里的 C 和 E 练到闭眼知道，上下行 + 短句回 C3。

## 图2：C Ionian E 型（E-shape）指型（7–12品，较高把位，可连接上一张）

这是标准 CAGED 五个形状里的 **E 型**（根音同时出现在 6 弦和 1 弦，因为这两根弦都是 E 调音），核心在 7–10 品，C3 出现在 6 弦 8 品；10–12 品是延伸到下一个 D 型指型的过渡音。

| 弦/品 | 7 | 8 | 9 | 10 | 11 | 12 |
|-------|---|---|---|----|----|----|
| 1弦（e） | B4 | **C5** |  | D5 |  | E5 |
| 2弦（B） |  | G4 |  | A4 |  | B4 |
| 3弦（G） | D4 |  | E4 | F4 |  | G4 |
| 4弦（D） | A3 |  | B3 | **C4** |  | D4 |
| 5弦（A） | E3 | F3 |  | G3 |  | A3 |
| 6弦（E） | B2 | **C3** |  | D3 |  | E3 |

**根音 C**：6弦8品 C3、4弦10品 C4、1弦8品 C5。
**三音 E**：5弦7品 E3、3弦9品 E4、1弦12品 E5、6弦12品 E3。

练法：从低把位（图1）爬或滑到这里，连接两个形状，始终能找到 C。

## 图3：C 大调五声音阶（同一 0–5品区域，更简单的 box）

只保留 C D E G A（去掉 F 和 B），立刻能用来即兴，手感更松。

| 弦/品 | 0 | 1 | 2 | 3 | 4 | 5 |
|-------|---|---|---|---|---|---|
| 1弦（e） | E4 |  |  | G4 |  | A4 |
| 2弦（B） |  | **C4** |  | D4 |  | E4 |
| 3弦（G） | G3 |  | A3 |  |  | **C4** |
| 4弦（D） | D3 |  | E3 |  |  | G3 |
| 5弦（A） | A2 |  |  | **C3** |  | D3 |
| 6弦（E） | E2 |  |  | G2 |  | A2 |

**根音 C** 和 **三音 E** 位置与图1相同（五声里 E 还在）。
先用这个弹短句和即兴，再回去加 F、B 变回完整大调。

## 图4：A Aeolian（自然小调，0–5品，同一组音换"家"）

音符和 C 大调完全一样，但根音改成 A，三音变成小三度 C，情绪立刻变悲伤。用来体会调式。

| 弦/品 | 0 | 1 | 2 | 3 | 4 | 5 |
|-------|---|---|---|---|---|---|
| 1弦（e） | E4 | F4 |  | G4 |  | **A4** |
| 2弦（B） | B3 | C4 |  | D4 |  | E4 |
| 3弦（G） | G3 |  | **A3** |  | B3 | C4 |
| 4弦（D） | D3 |  | E3 | F3 |  | G3 |
| 5弦（A） | **A2** |  | B2 | C3 |  | D3 |
| 6弦（E） | E2 | F2 |  | G2 |  | **A2** |

**根音 A**：5弦0品 A2、6弦5品 A2、3弦2品 A3、1弦5品 A4。
**三音 C（小三度）**：5弦3品 C3、2弦1品 C4、3弦5品 C4。

对比图1：同样的音，只是乐句改结束在 A 上，听区别。这就是调式的核心。

> 注意区分：图1→图4 是**关系大小调**（音符完全相同，主音不同）。还有一种容易搞混的是**同名大小调**（主音相同，音符不同，比如 C 大调 vs C 自然小调），这个概念和判断方法见 [调式理论基础.md](./调式理论基础.md) 第二节。

---

**怎么用这些图**：
每天选一张，10–15分钟。先定位粗体根音和三音，再跑音阶，最后强制短乐句回到根音。图1和图2连起来就是开始把脖子跑通；图3让你马上能solo；图4让你感受换家换情绪。

想让调式听感更明显，可以用 [和弦音阶对应表.md](./和弦音阶对应表.md) 里的 drone/vamp 练习法，配一个持续和弦垫底再即兴。

需要再加 G Mixolydian、D Dorian 或某个 3NPS 指型的图，直接说要哪一个。
