和弦功能与终止式

7 个顺阶和弦按角色分三组；乐句怎么"收尾"有 4 种固定公式。

三组功能

功能大调里的级数感觉
主功能（Tonic，"家"）I、vi稳定、可以停留
下属功能（Subdominant，"出门"）IV、ii离开主音，但不紧张
属功能（Dominant，"路上"）V、vii°紧张，想解决回 I

基本叙事：主 → 下属 → 属 → 主（从家出发，路上制造紧张，最后回家）。

四种终止式

终止式和弦走向效果
完全终止（Authentic）V → I最强的"回家"感
半终止（Half）任意 → V停在悬念上，像没说完的话
变格终止（Plagal，"阿门终止"）IV → I比完全终止柔和
阻碍终止（Deceptive）V → vi该回家却被"骗"到别处

C 大调实例

终止式和弦
完全终止G → C
半终止… → G
变格终止F → C
阻碍终止G → Am
